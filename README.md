# NetStudy React

ReactJS + Vite project organized by Pages and reusable Components.

## Structure
- `src/pages/`: one JSX + CSS file per screen/page
- `src/components/`: reusable Topbar, Sidebar, StitchPage
- `src/layouts/`: application shell
- `src/data/`: route/screen metadata
- `public/stitch-screens/`: original Stitch HTML and screenshots

The current visual content is sourced from the exported Stitch HTML under `public/stitch-screens`. The app does not yet use a backend API; application data is static/mock and can later be replaced by API services.

## Run
`npm install`
`npm run dev`
